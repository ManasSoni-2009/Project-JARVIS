# Multi-Agent Architecture

[[Welcome to JARVIS]] connects a supervisor router to five specialist agents:
1. **Chat Agent** — Conversational assistant with deep thinking.
2. **Browser Agent** — Live web search and URL synthesis.
3. **OS / OpenClaw** — Desktop automation adapter.
4. **MCP Client** — Filesystem, GitHub API, and ArXiv research tools.
5. **Obsidian Memory** — Markdown vault search, daily logs, and RAG synthesis.
